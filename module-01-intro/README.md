# Module 01 - Introduction

## What You'll Learn

- What Leptos is
- The view macro
- Components
- IntoView
- WASM logging
- How the concepts fit into a production Leptos 0.8 app

## Prerequisites

- Rust 1.89+
- `wasm32-unknown-unknown` target
- `trunk` for CSR modules or `cargo-leptos` for SSR modules

## How to Run

```bash
cd module-01-intro
trunk serve
```
