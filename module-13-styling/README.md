# Module 13 - Styling and Tailwind

## What You'll Learn

- Static classes
- Conditional classes
- Dynamic styles
- CSS variables
- Dark mode
- How the concepts fit into a production Leptos 0.8 app

## Prerequisites

- Rust 1.89+
- `wasm32-unknown-unknown` target
- `trunk` for CSR modules or `cargo-leptos` for SSR modules

## How to Run

```bash
cd module-13-styling
trunk serve
```
